# PRD: 임시 공간 탭

## 달성 가치
- **V1**: 핸즈프리 즉시 캡처 — 음성 캡처의 저장소
- **V3**: 영역 분리된 작업 관리 — 분류 전 미정 영역으로 작용

## 개요

분류되지 않은 항목들이 모이는 공간. 숏컷 음성 모드로 캡처된 항목, 빠르게 적은 메모, 출처/맥락이 아직 정리되지 않은 항목들이 일단 여기에 쌓인다. 사용자는 추후 이를 검토하고 개인 투두/회사 투두/루틴/문장 모음 등으로 분류한다.

**핵심 철학**: 캡처 시점에는 분류하지 않는다. 분류 부담이 캡처를 막지 않게 하는 것이 임시 공간의 존재 이유다.

## Acceptance Criteria

### AC1: 항목 자동 수집
- **설명**: 숏컷 음성 모드에서 입력된 모든 항목은 임시 공간에 자동 저장된다. 사용자는 분류 위치를 선택하지 않는다(되묻지 않음).
- **달성 가치**: V1
- **검증 방법**: 숏컷 호출 → 발화 → 종료 → 임시 공간 탭에서 항목 확인.

### AC2: 직접 메모 추가
- **설명**: 사용자는 임시 공간 탭 내에서도 직접 텍스트/음성으로 항목을 추가할 수 있다.
- **달성 가치**: V1
- **검증 방법**: 탭 내 추가 UI 동작 확인.

### AC3: 항목 메타데이터
- **설명**: 각 항목은 캡처 시각, 입력 방식(음성/텍스트/숏컷), 원문(음성의 경우 STT 결과)을 메타데이터로 가진다.
- **달성 가치**: V1
- **검증 방법**: 다양한 경로로 캡처된 항목들의 메타데이터 정확성 확인.

### AC4: 항목 분류 이동
- **설명**: 사용자는 임시 공간 항목을 개인 투두/회사 투두/루틴/자주 읽는 문장으로 명시적으로 이동할 수 있다. 이동 시 원본은 임시 공간에서 제거된다.
- **달성 가치**: V3
- **검증 방법**: 항목 선택 → 분류 대상 선택 → 이동 후 원본 제거, 대상 영역 생성 확인.

### AC5: 미분류 항목 카운트 표시
- **설명**: 임시 공간 탭에는 미분류 항목 개수가 배지로 표시되어, 사용자가 정리 필요 여부를 인지할 수 있다.
- **달성 가치**: V1, V3
- **검증 방법**: 항목 추가/이동/삭제 시 배지 카운트 정확성 확인.
