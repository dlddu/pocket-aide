# PRD: 아이폰 숏컷 음성 모드

## 달성 가치
- **V1**: 핸즈프리 즉시 캡처 — 시스템 진입점에서 1단계 만에 저장
- **V2**: 한·영 혼용 음성 인식 정확도 — 숏컷 호출에서도 동일한 정확도 보장

## 개요

아이폰의 시스템 숏컷(Shortcuts)으로 호출 가능한 음성 캡처 모드. 사용자는 앱을 열지 않고도 시스템 어디서나(잠금 화면, Siri, 단축어 위젯, 사이드 버튼 등) 호출하여 즉시 음성 입력할 수 있다.

**핵심 제약 (사용자 명시)**:
- **되묻지 않음** — 종료 시점에 분류·확인을 묻지 않는다.
- **저장 위치는 임시 공간 고정** — 사용자가 매번 선택하지 않는다.

## Acceptance Criteria

### AC1: 숏컷에서 호출 가능
- **설명**: 아이폰 숏컷 앱에서 본 앱이 제공하는 액션을 호출할 수 있다. 사용자는 이를 사이드 버튼·Siri·홈 화면·잠금 화면 위젯 등 시스템이 허용하는 모든 진입점에 연결할 수 있다.
- **달성 가치**: V1
- **검증 방법**: 숏컷 앱에서 액션 등록 → 다양한 진입점에서 호출 시 모드 진입 확인.

### AC2: 호출 즉시 녹음 시작
- **설명**: 숏컷이 호출되면 별도 화면 진입이나 버튼 탭 없이 즉시 녹음이 시작된다.
- **달성 가치**: V1
- **검증 방법**: 호출에서 녹음 시작까지 지연 시간 측정 (목표: 1초 이내).

### AC3: 종료 시 되묻기 없음
- **설명**: 사용자가 종료(예: 침묵 감지, 명시적 종료 동작)하면 시스템은 분류·태그·확인을 묻지 않고 임시 공간에 저장한다.
- **달성 가치**: V1
- **검증 방법**: 호출 → 발화 → 종료 → UI에 확인 다이얼로그가 등장하지 않는지, 임시 공간에 저장됐는지 확인.

### AC4: 임시 공간 자동 저장
- **설명**: 캡처된 항목은 STT 결과 + 원본 음성 메타데이터와 함께 임시 공간에 저장된다.
- **달성 가치**: V1
- **검증 방법**: 숏컷 호출 후 임시 공간 탭에서 항목과 메타데이터 확인.

### AC5: 음성 인식 모델은 STT 엔진 PRD 채택
- **설명**: 숏컷 음성 모드에서 사용하는 STT는 별도 PRD에서 정의된 한·영 혼용 최적 모델을 동일하게 사용한다.
- **달성 가치**: V2
- **검증 방법**: 채팅 탭의 음성 인식 결과와 동일 발화에 대해 동일한 결과를 내는지 확인.

### AC6: 시스템 권한 처리
- **설명**: 마이크 권한, 음성 인식 권한이 없는 경우 명확한 안내 후 시스템 권한 요청을 트리거한다. 사용자가 거부하면 그 사실을 임시 공간에 기록한다.
- **달성 가치**: V1
- **검증 방법**: 권한 미부여 상태에서 호출 → 안내 → 요청 흐름 확인.
