# PRD: AI 채팅 탭 (음성 대화 가능)

## 달성 가치
- **V5**: 자연어 대화 기반 작업 처리 — 텍스트/음성으로 자연 대화 인터페이스 제공
- **V2**: 한·영 혼용 음성 인식 정확도 — 음성 입력 시 STT 정확도 보장
- **V1**: 핸즈프리 즉시 캡처 — 음성 모드로 손 떼지 않고 대화 가능

## 개요

탭 6개 중 첫 번째 탭. 텍스트 입력과 음성 대화 모드를 모두 지원하는 AI 채팅 화면. 일반적인 대화·질문·요약·정리 등에 사용한다.

> **답하는 에이전트 (2026-11-06 사용자 결정)**: 채팅 탭은 [session-platform](https://github.com/dlddu/session-platform)의
> `codex` 워크로드(Codex SDK, 사용자의 ChatGPT 구독 로그인)가 답한다. 사용자마다 **codex 세션 하나를 오래 이어 쓴다** —
> 대화는 그 세션의 스레드에 이어지고, pocket-aide 는 읽을 수 있는 이력을 자기 DB(`chat_sessions`·`chat_messages`)에 남긴다.
> 백엔드는 채팅 탭 전용 ServiceAccount(`pocket-aide-chat`)의 토큰으로 플랫폼을 불러, 채팅 세션이 세션 탭과 다른 테넌트에 속하게 한다
> (session-platform `docs/prd/multitenancy.md`). 이전의 OpenRouter 직접 호출은 없앴다.

## Acceptance Criteria

### AC1: 텍스트 채팅 송수신
- **설명**: 사용자가 텍스트를 입력하면 codex 세션의 답을 받아본다. 보내기는 곧바로 접수되고(202), 답은 끝날 때까지 「입력 중」 말풍선에 쌓이다가 이력에 남는다 — 앱은 답을 기다리는 동안 대화를 짧은 간격으로 다시 읽는다. 앱을 닫거나 연결이 끊겨도 답은 서버가 끝까지 받아 남긴다. 한 번에 답 하나만 진행한다(진행 중 보내기는 409). 대화 이력은 보존된다.
- **달성 가치**: V5
- **검증 방법**: 입력 → 「입력 중」 → 답 수신 → 재진입 시 이력 유지 확인. 답을 기다리는 중 앱을 닫았다 열어도 답이 이력에 있는지 확인.

### AC2: 음성 대화 모드 진입
- **설명**: 채팅 화면 내 음성 모드 버튼으로 핸즈프리 음성 대화 모드에 진입한다. 진입 후에는 발화 → STT → LLM → TTS 응답이 자동으로 이어진다.
- **달성 가치**: V5, V1
- **검증 방법**: 버튼 한 번으로 진입, 진입 후 별도 조작 없이 한 차례 이상 음성 왕복 대화가 성립하는지 확인.

### AC3: 음성 입력의 한·영 혼용 인식
- **설명**: 한 문장 내에 한국어와 영어가 섞인 발화도 정확히 인식한다. 사용 모델은 한·영 혼용에서 정확도가 가장 높은 모델을 채택한다(별도 PRD에서 정의).
- **달성 가치**: V2
- **검증 방법**: 한·영 혼용 표준 발화 샘플 세트로 인식률 측정.

### AC4: 하나의 긴 대화
- **설명**: 채팅 탭은 사용자당 **하나의 대화**다(2026-11-06 사용자 결정 — 이전의 「새 대화 시작·과거 대화 목록·특정 대화 재개」를 대신한다). 대화는 하나의 codex 세션에 이어져 앞선 맥락을 기억하고, 탭을 떠났다 돌아와도·세션이 동결됐다 복원돼도 이어진다. 플랫폼 쪽 세션이 사라지면 다음 메시지가 새 세션을 열고 pocket-aide 의 이력은 그대로 남는다.
- **달성 가치**: V5
- **검증 방법**: 메시지 여러 개를 주고받은 뒤 앞선 내용을 가리키는 질문에 맥락대로 답하는지, 재진입 시 같은 대화가 이어지는지 확인.

### AC5: 음성 응답 중단 및 인터럽트
- **설명**: 음성 대화 모드 중 TTS 응답이 진행 중일 때 사용자가 발화를 시작하면 응답을 즉시 중단하고 사용자의 새 입력으로 전환한다.
- **달성 가치**: V5
- **검증 방법**: TTS 진행 중 사용자 발화 시작 → 응답 중단까지 지연 시간 측정.

### AC6: 스킬 새로고침
- **설명**: 채팅 화면 헤더의 「스킬 새로고침」으로, 대화를 유지한 채 codex 세션의 플러그인 스킬을 마켓플레이스에서 다시 받는다(session-platform AC-J7). 답이 진행 중일 때는 받지 않는다(409). 결과(추가·수정·삭제 개수, 또는 이미 최신)를 화면에 짧게 알리고, 다음 답부터 바뀐 스킬이 쓰인다. 첫 메시지 전에는 세션이 없어 누를 수 없다.
- **달성 가치**: V5
- **검증 방법**: 스킬을 바꾼 뒤 새로고침 → 결과 안내 → 다음 답이 바뀐 스킬을 따르는지 확인. 답이 진행 중일 때 버튼이 막히는지 확인.

### AC7: ChatGPT 로그인
- **설명**: codex 세션은 처음 쓸 때 사용자의 ChatGPT 계정으로 한 번 로그인한다. 첫 메시지의 답 자리에 기기 코드 로그인 안내(주소·일회용 코드)가 나오고, 사용자가 다른 기기에서 로그인을 마치면 같은 답이 이어서 첫 질문에 답한다. 안내의 주소는 눌러 브라우저로 열 수 있고(메시지 안의 웹 주소는 모두 링크다), 주소·코드는 복사할 수 있다. 로그인 요청 단계에서 플랫폼 세션 만들기가 게이트웨이 시간을 넘겨 실패해도, 이미 만들어진 같은 이름의 세션을 이어받아 메시지가 사라지지 않는다. 로그인은 세션에 남아 이후 메시지에는 다시 묻지 않는다.
- **달성 가치**: V5
- **검증 방법**: 첫 메시지 → 로그인 안내 → 로그인 → 같은 답 자리에 첫 질문의 답이 오는지, 다음 메시지에 로그인을 다시 묻지 않는지 확인.
