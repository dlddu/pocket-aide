# PRD: LLM 기반 타이핑 도구 (키보드 확장)

## 달성 가치
- **V7**: 시스템 전역 글쓰기 보조 — 어떤 앱의 텍스트 입력 창에서도 LLM 기반 편집 사용 가능

## 개요

iOS 키보드 확장(Custom Keyboard Extension)으로 구현된 LLM 기반 텍스트 편집 도구. 사용자는 메시지·메일·메모 등 어떤 텍스트 입력 창에서도 본 키보드로 전환하여 LLM 편집 기능을 사용할 수 있다.

**핵심 사용 시나리오**: 사용자가 텍스트를 입력 중이거나 이미 입력한 상태에서, 본 키보드의 LLM 편집 기능을 호출하여 다음과 같은 작업을 수행한다:
- 문장 다듬기 / 어조 변경 / 길이 조절
- 번역 (한 ↔ 영)
- 요약 / 확장 / 다시 쓰기
- 오타·문법 교정

## Acceptance Criteria

### AC1: iOS 키보드 확장 등록
- **설명**: 본 앱은 iOS의 Custom Keyboard Extension을 제공하며, 사용자는 시스템 설정에서 이를 등록·활성화할 수 있다.
- **달성 가치**: V7
- **검증 방법**: 설정 → 일반 → 키보드에서 본 키보드 등록 가능 여부 확인.

### AC2: 어떤 앱에서든 호출 가능
- **설명**: 등록된 키보드는 텍스트 입력이 가능한 어떤 앱에서도 키보드 전환을 통해 호출할 수 있다.
- **달성 가치**: V7
- **검증 방법**: 메시지·메일·메모·기타 임의 앱에서 본 키보드로 전환 가능한지 확인.

### AC3: 입력 텍스트에 대한 LLM 편집
- **설명**: 사용자가 현재 입력 창에 작성한 텍스트(또는 선택 영역)를 대상으로 LLM이 편집을 수행한다. 결과는 입력 창의 텍스트를 대체하거나, 사용자가 확인 후 적용한다.
- **달성 가치**: V7
- **검증 방법**: 텍스트 입력 → 편집 명령 → 결과가 입력 창에 반영되는지 확인.

### AC4: 기본 편집 명령 세트
- **설명**: 키보드는 다음 기본 편집 명령을 제공한다 (구체적 항목은 디자인에서 확정):
  - 어조 변경 (정중하게 / 캐주얼하게 / 단호하게 등)
  - 길이 조절 (짧게 / 길게)
  - 번역 (한 → 영, 영 → 한)
  - 교정 (오타·문법)
  - 자유 지시 (사용자 텍스트 명령)
- **달성 가치**: V7
- **검증 방법**: 각 명령 동작 확인.

### AC5: 자유 지시 입력
- **설명**: 미리 정의된 명령 외에, 사용자가 자유 지시("이걸 표 형태로", "예시를 추가해줘" 등)를 텍스트로 줄 수 있다.
- **달성 가치**: V7
- **검증 방법**: 자유 지시 입력 → LLM 응답 반영 확인.

### AC6: Full Access 권한 처리
- **설명**: LLM 호출에는 네트워크 접근이 필요하므로 키보드 확장에 "Full Access" 권한이 요구된다. 본 앱은 사용자에게 이 권한의 필요성을 명확히 안내하고, 권한 없이는 LLM 기능이 비활성화됨을 표시한다.
- **달성 가치**: V7
- **검증 방법**: Full Access 미부여 상태에서 LLM 명령 호출 → 비활성화 안내 표시 확인.

### AC7: 한·영 혼용 텍스트 대응
- **설명**: 입력 텍스트가 한·영 혼용일 경우에도 모든 편집 명령이 정상 작동한다.
- **달성 가치**: V7
- **검증 방법**: 한·영 혼용 텍스트로 각 명령 수행 시 결과 확인.

### AC8: 응답 지연 동안의 UX
- **설명**: LLM 호출은 시간이 걸린다. 키보드는 처리 중임을 명확히 표시하고, 사용자가 다른 작업을 할 수 있도록 비동기로 처리한다.
- **달성 가치**: V7
- **검증 방법**: 호출 중 UI 상태 확인 + 사용자 인터럽션 가능 여부 확인.

## 열린 질문

- **인증 모델**: 키보드 확장에서 메인 앱과 어떻게 인증/세션을 공유할지 (App Group, Keychain Sharing 등) 결정 필요.
- **프라이버시**: 키보드가 입력하는 모든 텍스트가 LLM 서버로 전송되는지 사용자에게 어떻게 투명하게 알릴지 결정 필요.
