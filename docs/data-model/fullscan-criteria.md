# 풀스캔 허용 기준

**사람이 소유한다.** 이 파일을 바꾸는 PR 은 수동 승인 케이스 MA5([`docs/review-policy.md`](../review-policy.md))라 사람이 승인해야 머지된다. data plane 은 기준을 착지시키지 않고, 인덱스로 닫히지 않는 패턴이 있으면 이 표에 넣을 행을 제안 PR 로 올린다 — 채택 여부는 그 PR 의 승인이 정한다.

체커(`backend/cmd/datamodelcheck`)는 이 표에서만 기준 ID 를 읽고, 카탈로그의 `풀스캔 허용(F<n>)` 은 여기 있는 ID 만 받는다. 표는 정확히 하나, 행은 `F<n> | 기준 | 관측 가능한 근거` 세 칸이다. 지워진 ID 는 재사용하지 않는다. 현황 서술(어느 패턴이 왜 인덱스로 닫히지 않는가)은 [`README.md`](README.md) §2 에 둔다.
