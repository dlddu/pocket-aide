# 사용자 여정: 자기 되새김 사용자 — 위젯에서 다짐과 일상 정보를 한눈에 보기

## 페르소나
- **이름/역할**: 자기에게 자주 되새기고 싶은 문장(다짐, 가치, 인용)을 가지고 있고, 동시에 일정·메일·날씨 같은 일상 정보도 한 곳에서 빠르게 확인하고 싶은 사용자.
- **상황**: 하루에도 여러 번 홈 화면을 본다. 매번 캘린더·메일·날씨 앱을 따로 열기는 번거롭다. 자기 다짐도 마음먹고 따로 펼쳐 보지 않으면 잊어버린다.
- **목표**: 홈 화면을 잠깐 보는 순간 다짐 한 줄과 오늘의 정보(일정·메일·날씨·알림)를 함께 받는다. 다짐은 매번 다른 문장이 보이도록 회전 노출된다.

## 달성 가치
- **V4 의도된 반복 노출**: 다짐 탭에 등록한 문장이 위젯의 한 영역에서 회전 노출되어, 사용자가 의도적으로 앱을 열지 않아도 자주 마주치게 된다 (PRD-5 AC2~AC4, PRD-8 AC5).
- **V6 일상 정보 통합 시야**: 일정·메일·날씨·다짐·아이폰 알림이 한 위젯에서 통합 노출되므로 여러 앱을 열지 않아도 된다 (PRD-8 AC1~AC8).

## 사전 조건
- 사용자가 본 앱을 설치했고 캘린더·메일·위치(날씨용) 권한을 허용했다.
- 홈 화면에 본 앱의 위젯이 추가되어 있다.

## 단계 흐름

### S1: 다짐 탭에서 자주 읽을 문장을 등록·우선순위 지정
- **사용자 행동**: 자주 읽고 싶은 문장을 다짐 탭에 추가하고, 각 문장의 노출 우선순위(높음/보통/낮음)를 지정한다. 임시 공간에서 옮겨오기도 한다.
- **시스템 응답**: 다짐 탭에 문장 목록이 표시된다. 우선순위가 시각적으로 구분(우선순위 도트 등)되어 보이고, 탭 상단의 hero 영역에는 임의의 문장 한 줄이 회전 노출된다 (PRD-5 AC1~AC3).
- **시각화 mockup**: screen-affirmations.html (HERO 회전 영역 + 목록 + 우선순위 도트)

### S2: 홈 화면 위젯에서 통합 정보를 한눈에 확인
- **사용자 행동**: 홈 화면을 본다. 위젯을 따로 탭하지 않고 그냥 시야에 들어오게 둔다.
- **시스템 응답**: 본 앱 위젯 1개가 다섯 영역(날씨·캘린더·메일·다짐·알림)을 한 화면에 표시한다. 위젯 크기에 따라 영역이 축약·확장되며, iOS 위젯 갱신 정책 내에서 정보 신선도가 유지된다 (PRD-8 AC1~AC4, AC6, AC7).
- **시각화 mockup**: screen-widget.html (large widget — 날씨/캘린더 한 줄, 다짐 중앙, 메일/알림 한 줄)

### S3: 위젯의 다짐 영역이 갱신 주기마다 회전
- **사용자 행동**: 시간이 지나 위젯이 갱신되는 시점에 홈 화면을 다시 본다.
- **시스템 응답**: 다짐 영역에 이전과 다른 문장이 노출된다. 우선순위가 높은 문장은 더 자주 등장한다 (PRD-8 AC5, PRD-5 AC2와 연동).
- **시각화 mockup**: screen-widget.html (middle: affirmation rotating 영역)

### S4: 위젯 영역 탭으로 대응 화면에 진입
- **사용자 행동**: 위젯의 다짐 영역(또는 다른 영역)을 탭한다.
- **시스템 응답**: 앱이 열리며 해당 영역에 대응하는 탭/화면으로 바로 진입한다. 다짐 영역을 탭한 경우 다짐 탭이 열린다 (PRD-8 AC8).
- **시각화 mockup**: screen-affirmations.html (다짐 탭으로 진입한 결과 화면)

### S5: 다짐 탭에서 임의 문장을 음성으로 듣기
- **사용자 행동**: 다짐 탭의 임의 문장을 탭한다.
- **시스템 응답**: 해당 문장이 TTS로 재생된다. "읽어줘야 하는 문장"이라는 이름에 대응하는 청각 채널이 동작한다 (PRD-5 AC5).
- **시각화 mockup**: screen-affirmations.html (목록 항목 탭 → TTS 재생, 별도 mockup 없음 — 동일 화면)

## 비고
- S2~S3는 동일 mockup `screen-widget.html`을 가리키지만, S3는 **시간 경과에 따른 갱신 후 상태**를 의미한다. 정적 mockup 한 장이 두 시점을 모두 표현하므로 별도 파일이 추가되지 않으면 동일 파일을 참조한다.
- 위젯의 "아이폰 알림 모음"(PRD-8 AC6)은 iOS 정책상 다른 앱 알림 직접 접근이 제한된다. 본 앱이 발행한 알림(루틴·투두 마감 등) 모음으로 한정될 가능성이 있고, 그 경우 V6의 "아이폰 알림" 정의가 좁혀진다 — 본 여정 자체는 영향받지 않으나 PRD 측 열린 질문이 해소되면 시스템 응답 묘사를 갱신한다.
- 본 여정은 V8(일상 루틴 구조화)는 다루지 않는다. 루틴 페르소나는 별도 여정에서 작성한다.
