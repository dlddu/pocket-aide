# 사용자 여정: 자기 다짐 노출 받고 싶은 사용자 — 다짐 등록부터 위젯 회전 노출까지

## 페르소나

- **이름/역할**: 자기 자신에게 반복적으로 상기시키고 싶은 문장(다짐, 가치, 인용, 짧은 메모)을 가진 사용자.
- **상황**: 한 번 적어두고 끝내는 게 아니라, 의도적으로 자주 마주치고 싶은 문장이 누적되어 있는 상태. 앱을 일부러 열지 않아도 일상 속에서 우연히 마주치길 원함.
- **목표**:
  - 문장을 손쉽게 등록·관리한다.
  - 앱에 들어올 때마다 다른 문장을 만나게 된다.
  - 홈 화면 위젯에서도 다짐 문장이 회전 노출되어 앱을 일부러 열지 않아도 자연스럽게 눈에 들어온다.

## 달성 가치

- **V4 의도된 반복 노출** — 본 여정의 단일 핵심 가치. 등록(S1), 우선순위(S2), 앱 내 회전(S3), TTS(S4), 위젯 회전(S5), 위젯에서 앱으로의 진입(S6) 전체가 V4의 단일 흐름으로 구현됨.

> **참고 — V6는 본 여정에서 다루지 않음**: 위젯 안에서 다짐이 캘린더·날씨·메일·알림과 함께 노출된다는 사실은 V6(일상 정보 통합 시야)의 환경적 결과일 뿐, 본 페르소나의 목표는 다짐 반복 노출이지 통합 시야 활용이 아니다. V6는 별도 여정("통합 시야 사용자")에서 다루도록 분리한다.

## 사전 조건

- 위젯이 홈 화면에 한 번 추가되어 있다. (위젯 추가 자체는 iOS 기본 흐름이며 별도 여정으로 분리 가능.)

## 단계 흐름

### S1: 다짐 문장 추가

- **사용자 행동**: "자주 읽어줘야 하는 문장" 탭에 진입하여 새 문장을 입력하거나, 임시 공간(Scratchpad)에서 옮겨온다.
- **시스템 응답**: 입력된 문장이 목록에 추가된다. 기본 우선순위(보통)로 등록.
- **시각화 mockup**: screen-affirmations.html (list 영역)
- **관련 AC**: PRD-5 / AC1

### S2: 노출 우선순위 설정

- **사용자 행동**: 등록한 문장에 대해 우선순위(높음/보통/낮음)를 지정한다.
- **시스템 응답**: 우선순위가 저장된다. 이후의 회전 노출(앱 내·위젯 모두)에서 이 우선순위가 가중치로 작용한다. 목록에는 우선순위 도트로 시각 표시.
- **시각화 mockup**: screen-affirmations.html (priority dots 영역)
- **관련 AC**: PRD-5 / AC2

### S3: 앱 내 자동 회전 노출 (탭 진입 시)

- **사용자 행동**: 사용자가 일과 중 임의 시점에 다짐 탭에 진입.
- **시스템 응답**: 탭 상단(HERO 영역)에 등록된 문장 중 하나가 우선순위 가중치에 따라 회전 노출된다. 다음에 진입할 때는 다른 문장이 노출됨.
- **시각화 mockup**: screen-affirmations.html (HERO: rotating affirmation 영역)
- **관련 AC**: PRD-5 / AC3

### S4: 음성으로 듣기 (선택)

- **사용자 행동**: 목록의 임의 문장을 탭한다.
- **시스템 응답**: TTS로 해당 문장이 재생된다. "읽어줘야 하는 문장"이라는 명명에 대응하는 흐름.
- **시각화 mockup**: screen-affirmations.html (list 영역 — 탭 동작)
- **관련 AC**: PRD-5 / AC5

### S5: 홈 화면 위젯에서 회전 노출

- **사용자 행동**: 앱을 열지 않고 단순히 홈 화면을 본다.
- **시스템 응답**: 통합 위젯의 다짐 영역에 등록된 문장 중 하나가 회전 노출된다. 위젯 갱신 주기마다 다른 문장이 표시됨 (우선순위 가중치 반영).
- **시각화 mockup**: screen-widget.html (Home screen with large widget — middle: affirmation rotating 영역)
- **관련 AC**: PRD-5 / AC4 + PRD-8 / AC5, AC7

### S6: 위젯 다짐 영역 탭 → 앱의 다짐 탭으로 진입

- **사용자 행동**: 위젯에 노출된 다짐 문장이 마음에 들어 더 보고 싶거나 편집하고 싶어 해당 영역을 탭.
- **시스템 응답**: 앱이 열리면서 곧장 "자주 읽어줘야 하는 문장" 탭에 진입. 사용자는 S1~S4의 흐름으로 돌아갈 수 있다(편집·우선순위 조정·TTS 등).
- **시각화 mockup**: screen-widget.html (Standalone widget detail — affirmation full width 영역) → screen-affirmations.html
- **관련 AC**: PRD-8 / AC8

## 가치 달성 평가

- **V4**: 등록(S1) → 우선순위(S2) → 앱 내 회전(S3) → 위젯 회전(S5)의 사슬이 "한 문장을 의도적으로 자주 마주치게 한다"는 V4 정의에 직접 대응. ✅

## 끊긴 연결 / 미해결

- **위젯 추가 자체의 온보딩**: 사전 조건으로 가정. 별도 여정으로 분리 가능 (현재 미작성).
- **V6 통합 시야 측면**: 본 여정 범위 밖. 위젯 mockup은 V6도 시각화하므로, 캘린더·메일·날씨·알림을 일상 시야로 활용하는 페르소나의 별도 여정이 필요하다 ("통합 시야 사용자" 후보).
- **V5 미커버**: 본 여정은 V5(자연 대화)와 무관. screen-chat-text/voice가 어떤 여정에도 매핑되지 못한 상태는 별도 여정 추가가 필요하다.
