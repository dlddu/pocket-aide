## 1. 서비스 개요 (참고)

PocketAide 제품 개요와 가치는 [`../product/values.md`](../product/values.md)를 따른다. 이 여정은 "자주 읽어줘야 하는 문장" 탭(PRD-5)과 통합 위젯(PRD-8)의 다짐 영역만 다룬다.

## 2. 여정 정의

**대상 사용자 (페르소나)**
사용자 본인. 자기 다짐·가치·인용 문장을 자주 되새기고 싶지만, 바쁜 일상에서 따로 시간을 내어 노트를 펼쳐 보지는 않는다. 앱 내 탭과 홈 화면 위젯을 매일 여러 번 스친다.

**진입 맥락**
책·대화·회고에서 마음에 남는 문장을 만났거나, 임시공간에 던져둔 메모 중 "다짐"으로 남길 문장이 있다.

**트리거**
"이건 잊으면 안 되는데"라고 느낀 문장이 생긴 순간.

**사용자 목표**
정해 둔 문장이 별도의 노력 없이 일상의 여러 접점(앱 내 다짐 탭, 홈 화면 위젯)에 반복해서 나타나 자연스럽게 내면화되는 것.

**완료 기준**
새로 등록한 문장이 위젯 다짐 영역에 한 번 이상 노출되고, 사용자가 그 영역을 탭해 다짐 탭에 진입한다(위젯 → 다짐 탭 진입 이벤트).

## 3. 단계별 상세

> 단계 식별자는 순번이 아닌 슬러그를 쓴다. 순서가 바뀌어도 식별자는 유지한다.

### `STP-add-affirmation` 다짐 문장 등록

- **사용자 행동**: 다짐 탭 헤더의 `+`를 눌러 시트 하나에서 문장을 쓰고 노출 빈도(높음/보통/가끔)를 고른 뒤 저장한다.
- **터치포인트**: 다짐 탭 — 추가 시트(문장 입력 + 우선순위 선택, 편집 시트 패턴)
- **생각·감정**: "잊기 전에 일단 적어두자." / "이건 매일 봐야 해."
- **페인포인트 / 이탈 위험**: 입력이 번거로우면 "나중에"로 미루다 잊는다 → 헤더 버튼 한 번으로 시트를 열고, 빈도는 3단계 단일 선택에 기본값 "보통"을 둔다. 저장 전에 닫으면 아무것도 남지 않으므로, 저장 버튼이 주 행동으로 분명해야 한다(PRD-5 AC1, AC2).

### `STP-rotation-in-app` 앱에서 회전 문장 마주치기

- **사용자 행동**: 잠깐 시간이 날 때 앱을 열어 다짐 탭에 들어간다.
- **터치포인트**: 다짐 탭 상단 회전 카드(히어로)
- **생각·감정**: "아, 이거 있었지." — 들어올 때마다 다른 문장이라 새로움이 있다.
- **페인포인트 / 이탈 위험**: 같은 문장만 반복되면 금방 무뎌진다 → 우선순위 가중 회전으로 진입마다 다른 문장을 보여준다(PRD-5 AC3).

### `STP-widget-glance` 홈 화면 위젯에서 마주치기

- **사용자 행동**: 잠금 해제 직후나 다른 앱으로 가는 길에 홈 화면을 스친다. 별도 행동 없이 위젯 다짐 영역의 문장을 본다.
- **터치포인트**: 홈 화면 통합 위젯 — "오늘의 다짐" 영역
- **생각·감정**: "오늘도 이 문장이네." — 의도하지 않은 순간의 재노출.
- **페인포인트 / 이탈 위험**: iOS 위젯 갱신 주기 때문에 방금 등록한 문장이 바로 보이지 않을 수 있다 → 문장 추가·우선순위 변경 시 위젯 갱신을 요청한다(가정 — 구현 방식 미확정)(PRD-5 AC4, PRD-8 AC5).

### `STP-widget-to-app` 위젯에서 다짐 탭으로 들어가기

- **사용자 행동**: 위젯에서 본 문장이 마음에 걸려 다짐 영역을 탭한다.
- **터치포인트**: 위젯 다짐 영역 → 앱 다짐 탭
- **생각·감정**: "이거 좀 더 보고 싶다."
- **페인포인트 / 이탈 위험**: 탭 후 앱의 다른 탭이 열리면 흐름이 끊긴다 → 다짐 탭으로 바로 진입하고(PRD-8 AC8), 위젯에서 보던 문장을 히어로에 그대로 보여준다(가정 — PRD 미정의).

## 4. 분기·예외 흐름

| 상황 | 처리 | 이어지는 단계 |
|---|---|---|
| 우회 경로 — 임시공간 메모를 다짐으로 이동 | 임시공간 카드의 `→ 다짐` 칩을 누르면 문장이 곧바로 "보통"으로 저장되고 우선순위 시트가 열린다. 여기서 취소해도 문장은 "보통"으로 남는다(임시공간 이동 구현 기준 — PR #64, 머지 전) | `STP-rotation-in-app` |
| 중도 이탈 — 추가 시트에서 취소 | 시트가 닫히고 아무것도 저장되지 않는다. 목록은 그대로다 | 해당 없음 (여정 밖 종료) |
| 실패 케이스 — 등록된 문장이 없음 | 다짐 탭·위젯이 빈 상태 안내를 보여주고 첫 문장 등록으로 유도한다 | `STP-add-affirmation` |
| 외부 지연 — 위젯 갱신 대기 | 위젯에 이전 문장이 남아 있음. 다음 갱신 주기에 반영된다(사용자 조치 불필요) | 해당 없음 |
| 이탈 — 홈 화면에 위젯 미설치 | 여정은 앱 내 노출(`STP-rotation-in-app`)까지만 이어지고, 위젯 접점 없이 끝난다 | 해당 없음 (여정 밖 종료) |
