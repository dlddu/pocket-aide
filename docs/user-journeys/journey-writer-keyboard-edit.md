# 사용자 여정: 메시지 작성자 — 키보드 확장으로 텍스트 다듬기

## 페르소나
- **이름/역할**: 메시지·메일·메모를 자주 작성하는 사용자
- **상황**: 한국어와 영어가 섞인 텍스트를 자주 쓰며, 어조 조정·번역·교정·재작성을 빈번하게 필요로 한다. 매번 LLM 앱에 텍스트를 복사·붙여넣기하는 흐름이 번거롭다고 느낀다.
- **목표**: 작성 중인 입력 창을 떠나지 않고 그 자리에서 텍스트를 다듬어 적용한다.

## 달성 가치
- **V7 시스템 전역 글쓰기 보조**: 사용자가 어떤 앱의 텍스트 입력 창에 있든 동일한 키보드를 호출해 LLM 편집을 즉시 사용한다. 앱 전환·복붙이 불필요해지므로 V7의 핵심을 직접 만족시킨다.
- **V2 한·영 혼용 음성/텍스트 인식**: 입력 텍스트가 한·영 혼용이어도 어조·길이·번역·교정 모든 명령이 정상 작동하므로 V2의 텍스트 측면을 보완한다 (PRD-9 AC7).

## 사전 조건
- iOS 설정에서 PocketAide 키보드가 등록되어 있고 **Full Access** 권한이 부여되어 있다 (PRD-9 AC1, AC6). 권한 미부여 시 LLM 명령이 비활성화 상태로 표시된다.

## 단계 흐름

### S1: 호스트 앱에서 텍스트 작성 중 본 키보드로 전환
- **사용자 행동**: 메일·메시지·메모 등 임의 호스트 앱의 입력 창에서 글을 쓰다가, 시스템 지구본 키(🌐)로 PocketAide 키보드로 전환한다.
- **시스템 응답**: 화면 하단 키보드 영역이 PocketAide 키보드로 교체된다. 상단 LLM 툴바가 노출되며, Full Access 상태가 헤더에 표시된다 (켜짐/꺼짐).
- **시각화 mockup**: screen-keyboard-extension.html (호스트 앱 = Mail composer + 하단 키보드 확장 영역)

### S2: 편집 명령 선택 또는 자유 지시 입력
- **사용자 행동**: 작성한(또는 선택한) 텍스트를 대상으로 명령 칩(어조·길이·번역·교정) 중 하나를 탭하거나, 자유 지시 입력창에 "예시 추가해줘"·"표 형식으로" 같은 자연어 지시를 입력한다.
- **시스템 응답**: 명령 칩 또는 자유 지시가 활성 상태로 표시되고, 대상 텍스트(현재 입력 중인 텍스트 또는 선택 영역)가 LLM에게 전달된다.
- **시각화 mockup**: screen-keyboard-extension.html (LLM 툴바 — 명령 칩 그룹: 어조 / 길이 / 번역 / 교정 + 자유 지시 입력)

### S3: 비동기 처리 동안 진행 상태 확인
- **사용자 행동**: LLM 응답을 기다리는 동안 다른 작업을 계속할 수 있다. 필요 시 인터럽션도 가능하다.
- **시스템 응답**: 키보드 영역에 처리 중 상태가 명확히 표시된다(로딩 인디케이터 등). 메인 입력 창은 그대로이며, 사용자는 동일 키보드 안에서 다른 명령을 탐색할 수 있다 (PRD-9 AC8).
- **시각화 mockup**: screen-keyboard-extension.html (async loading state 영역)

### S4: 결과를 입력 창에 반영
- **사용자 행동**: 결과를 확인하고 그대로 적용하거나(대체) 명령을 다시 시도한다.
- **시스템 응답**: LLM 결과가 호스트 앱의 입력 창 텍스트를 대체(또는 사용자 확인 후 적용)한다. 사용자는 키보드를 그대로 둔 채 다음 문장을 이어 쓰거나 다시 명령을 호출할 수 있다.
- **시각화 mockup**: screen-keyboard-extension.html (호스트 앱 메일 본문 텍스트가 갱신된 상태)

## 비고
- 본 여정의 모든 단계는 단일 mockup `screen-keyboard-extension.html`로 시각화된다. 해당 mockup은 한 화면 안에 호스트 앱(상단)과 키보드 확장(하단)을 함께 그리고, 명령 칩·자유 지시·비동기 로딩 상태를 한 화면에서 모두 보여준다. 단계별 별도 mockup이 추가될 경우 본 문서와 `mockups/_index.md`를 함께 갱신한다.
- 음성 입력으로 호스트 앱에 텍스트를 넣는 흐름(예: 시스템 받아쓰기)은 본 여정의 범위 밖이며, V1·V2 음성 캡처 여정에서 다룬다.
