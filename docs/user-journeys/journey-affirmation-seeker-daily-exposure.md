# 사용자 여정: 다짐 추구자 — 일상 반복 노출

## 페르소나
- **이름/역할**: 자기 다짐을 자주 되새기고 싶은 사용자 (자기계발 의식이 강한 직장인, 자신만의 가치/습관을 잊지 않으려는 사람)
- **상황**: 일상이 바쁘고 정보가 많아, 자기 자신에게 의도적으로 정해둔 다짐·가치·인용 문장을 깜빡 잊기 쉽다. 따로 시간을 내어 일기/노트를 펼쳐 보지 않는다.
- **목표**: 자기 다짐이 일상의 다양한 접점(앱 내 탭, 홈 화면 위젯)에서 의도적으로 반복 노출되어, 별도의 시간을 들이지 않아도 자연스럽게 내면화된다.

## 달성 가치
- **V4 (의도된 반복 노출)** — 사용자가 의도적으로 정한 문장이 앱 내 회전 노출과 홈 화면 위젯 양쪽에서 반복 등장한다. 이 여정의 모든 단계는 "사용자가 결정한 문장을 사용자의 시야에 반복적으로 들이는 것" 자체에 기여한다.

> **참고**: 이 여정은 V4에만 집중한다. `screen-widget`은 V6(일상 정보 통합 시야)도 시각화하지만, 본 여정은 위젯의 다짐 슬라이스 측면(V4)만 단계로 사용한다. V6 측면(일정/메일/날씨/알림 통합)을 다루는 여정은 아직 정의되지 않았다.

## 단계 흐름

### S1: 다짐 문장 등록
- **사용자 행동**: 다짐 탭에 진입해 새 문장(예: "오늘은 한 가지만 끝내자")을 직접 입력해 추가하거나, 임시 공간에서 다짐 탭으로 이동시킨다.
- **시스템 응답**: 다짐 목록에 새 문장이 추가된다. 이 시점부터 회전 노출 풀의 일원이 된다.
- **시각화 mockup**: `screen-affirmations.html` (다짐 탭 — 카드 입력 영역)
- **참조 PRD/AC**: PRD-5 AC1 (문장 추가/편집/삭제)

### S2: 노출 우선순위 설정
- **사용자 행동**: 추가한 문장의 노출 우선순위를 정한다 (높음/보통/낮음 또는 가중치).
- **시스템 응답**: 우선순위가 저장되어 이후 회전 노출과 위젯 노출 빈도에 반영된다.
- **시각화 mockup**: `screen-affirmations.html` (다짐 카드의 우선순위 인디케이터)
- **참조 PRD/AC**: PRD-5 AC2 (노출 빈도 설정)

### S3: 앱 내 다짐 탭 진입 — 회전 노출 마주침
- **사용자 행동**: 잠깐의 시간이 났을 때, 앱을 열어 다짐 탭으로 진입한다.
- **시스템 응답**: 등록된 문장 중 하나가 우선순위에 따라 임의로 회전 노출된다. 진입할 때마다 다른 문장이 보인다.
- **시각화 mockup**: `screen-affirmations.html` (회전 노출되는 큰 카드)
- **참조 PRD/AC**: PRD-5 AC3 (앱 내 자동 회전 노출)

### S4: 홈 화면 위젯에서 다짐 마주침
- **사용자 행동**: 의도하지 않은 순간(잠금 해제 직후, 다른 앱으로 가는 길)에 홈 화면을 본다.
- **시스템 응답**: 위젯의 다짐 슬라이스에서 회전 중인 문장이 노출되어 있다. 사용자는 별도 행동 없이 다짐을 한 번 더 마주친다.
- **시각화 mockup**: `screen-widget.html` (위젯 다짐 슬라이스)
- **참조 PRD/AC**: PRD-5 AC4 (위젯 연계), PRD-8 AC5 (자주 읽어줘야 하는 문장 회전 노출)

### S5: 위젯 → 다짐 탭 진입 → 음성으로 듣기
- **사용자 행동**: 위젯에서 본 문장이 마음에 들어, 다짐 영역을 탭해 앱에 진입한다. 회전 중인 문장을 다시 한 번 탭해 음성으로 듣는다.
- **시스템 응답**: 위젯 탭 → 다짐 탭으로 진입한다. 문장 탭 시 TTS로 다짐을 음성 출력한다.
- **시각화 mockup**: `screen-widget.html` → `screen-affirmations.html`
- **참조 PRD/AC**: PRD-8 AC8 (위젯 영역 탭 시 앱 진입), PRD-5 AC5 (음성으로 듣기)

## 단계별 mockup 매핑 요약

| 단계 | mockup | 비고 |
|------|--------|------|
| S1 | screen-affirmations | 등록 영역 |
| S2 | screen-affirmations | 우선순위 설정 |
| S3 | screen-affirmations | 회전 노출 카드 |
| S4 | screen-widget | 위젯 다짐 슬라이스 (V4 측면) |
| S5 | screen-widget → screen-affirmations | 진입 + TTS |

## 시각화 누락 / 열린 항목

- 단계 S2의 "우선순위 인디케이터"가 현재 `screen-affirmations.html` mockup에 명확히 시각화돼 있는지는 별도 mockup 검증이 필요. 명시적이지 않다면 mockup 보완 또는 본 여정의 단계 통합 후보.
- 본 여정은 단일 페르소나·단일 가치(V4) 여정이다. 위젯 V6 측면을 다루는 여정과 통합하지 않은 것은 의도적 — V4의 "반복 노출" 가치 흐름을 끊김 없이 보여주기 위함.
