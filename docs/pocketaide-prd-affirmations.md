# PRD: 자주 읽어줘야 하는 문장 모음 탭

## 달성 가치
- **V4**: 의도된 반복 노출 — 사용자가 자주 되새겨야 할 문장을 의도적으로 반복 노출

## 개요

사용자가 자기 자신에게 반복적으로 상기시키고 싶은 문장(다짐, 가치, 인용, 메모)을 모아두는 탭. 단순 저장이 아니라 **반복 노출**이 핵심 가치이며, 위젯과 연계되어 앱 외부에서도 자주 보여진다.

## Acceptance Criteria

### AC1: 문장 추가/편집/삭제
- **설명**: 사용자는 문장을 직접 입력하거나, 다른 탭(임시 공간 등)에서 이동시켜 추가할 수 있다. 편집·삭제도 가능하다.
- **달성 가치**: V4
- **검증 방법**: CRUD 동작 확인.

### AC2: 노출 빈도 설정
- **설명**: 각 문장은 노출 우선순위(높음/보통/낮음 또는 가중치)를 가지며, 위젯·앱 내 표시에서 이 우선순위에 따라 노출 빈도가 달라진다.
- **달성 가치**: V4
- **검증 방법**: 우선순위 다른 문장들의 위젯 노출 횟수 분포 확인.

### AC3: 앱 내 자동 회전 노출
- **설명**: 탭 진입 시 또는 탭 상단에 임의의 문장이 회전 노출되어, 사용자가 이 탭에 들어올 때마다 다른 문장을 보게 된다.
- **달성 가치**: V4
- **검증 방법**: 반복 진입 시 다른 문장이 노출되는지 확인.

### AC4: 위젯 연계
- **설명**: 위젯(별도 PRD)에서 이 탭의 문장이 표시 영역 중 하나로 노출된다. 위젯의 갱신 주기에 맞춰 문장이 회전한다.
- **달성 가치**: V4
- **검증 방법**: 위젯에 등록된 문장이 정상 표시되고, 탭 내 변경 사항이 위젯에 반영되는지 확인.

### AC5: 음성으로 듣기
- **설명**: 사용자는 임의 문장을 탭하면 TTS로 들을 수 있다. 이는 "읽어줘야 하는 문장"이라는 이름에 대응한다.
- **달성 가치**: V4
- **검증 방법**: 문장 탭 → TTS 음성 출력 동작 확인.
