설계 노트
  • 각 영역의 다크 표면 / ink / accent / rule / soft 5개 토큰은 tokens.md §1.9 표를 그대로 따른다. 임의의 hex는 사용하지 않는다.
  • 음성 모드(02)는 라이트 모드에도 이미 다크 표면을 쓰던 영역(§1.7)이므로 본 갤러리에서 변동 없음. 다만 AI 채팅 다크(01)와 표면 색은 공유(#0F1614)하되 본문 톤이 다르다(흰색 vs #ECEAE3).
  • 시스템 통합 3화면(08·09·10)은 iOS 시스템 다크 컨벤션 — 페이지 #000000, 카드 #1C1C1E, 구분선 #2C2C2E, 보조 텍스트 #8E8E93. PocketAide 강조는 영역 강조색을 점/라벨로 최소 노출.
  • V3(영역 분리) 원칙은 다크 변형에서도 유지 — 영역 간 다크 토큰을 섞지 않는다.
