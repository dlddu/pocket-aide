푸시 기기 등록 — 로그인 뒤 이 기기 이름이 아직 정해지지 않았으면 한 번 묻는다. 기본값은 기기 모델명, 최대 40자. 「저장」은 이름과 함께 푸시 토큰을 등록하고, 「건너뛰기」·바깥 탭은 이름 없이 등록한다. 어느 쪽이든 다시 묻지 않으며, 이후 토큰 갱신은 같은 이름으로 다시 등록한다. 디자인 시스템: components §9 오버레이(Sheet/Backdrop/Handle) + Card·PlainTextField, patterns §9 편집 시트. 시트는 푸시 계열이라 PR 모니터 팔레트(tokens §1.11).
