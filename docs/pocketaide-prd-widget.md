# PRD: 통합 위젯 (1개)

## 달성 가치
- **V6**: 일상 정보 통합 시야 — 일정·메일·날씨·자주 읽는 문장·아이폰 알림을 하나의 위젯에서 노출
- **V4**: 의도된 반복 노출 — 자주 읽어줘야 하는 문장을 위젯을 통해 외부에서도 노출

## 개요

홈 화면에 배치되는 위젯 1개. 사용자의 일상 정보를 한 화면에 통합 노출하는 것이 목적이다. 위젯 1개로 다섯 가지 정보 영역을 표시한다:

1. **캘린더** — 다가오는 일정
2. **메일** — 최근/미확인 메일 요약
3. **날씨** — 현재/오늘 날씨
4. **자주 읽어줘야 하는 문장** — 회전 노출
5. **아이폰 알림 모음** — 시스템 알림 요약

## Acceptance Criteria

### AC1: 단일 위젯에 다섯 영역 표시
- **설명**: 위젯 1개 내에 다섯 정보 영역이 모두 표시된다. 위젯 크기에 따라 영역의 표현 방식(축약/확장)이 달라질 수 있다.
- **달성 가치**: V6
- **검증 방법**: 위젯 추가 후 다섯 영역 모두 가시 확인.

### AC2: 캘린더 연동
- **설명**: iOS 시스템 캘린더를 읽어 다가오는 일정 1~3개를 노출한다.
- **달성 가치**: V6
- **검증 방법**: 시스템 캘린더에 일정 추가 → 위젯 갱신 → 표시 확인.

### AC3: 메일 연동
- **설명**: 사용자의 메일 계정에서 최근 미확인 메일을 요약 노출한다. 표시 형태(개수, 최신 발신자/제목 등)는 디자인에서 결정.
- **달성 가치**: V6
- **검증 방법**: 메일 도착 → 위젯에 반영 확인.

### AC4: 날씨 연동
- **설명**: 사용자의 현재 위치 또는 설정된 위치의 현재 기온, 날씨 상태, 강수 가능성 등을 노출한다.
- **달성 가치**: V6
- **검증 방법**: 위치 권한 부여 → 날씨 정보 정확성 확인.

### AC5: 자주 읽어줘야 하는 문장 회전 노출
- **설명**: 자주 읽어줘야 하는 문장 탭에 등록된 문장 중 하나가 위젯에 노출된다. 위젯 갱신 주기마다 회전된다. 노출 우선순위는 해당 탭의 우선순위 설정을 따른다.
- **달성 가치**: V4
- **검증 방법**: 갱신 주기 동안 다른 문장이 노출되는지, 우선순위에 따른 빈도 차이 확인.

### AC6: 아이폰 알림 모음
- **설명**: 시스템 알림 중 표시 가능한 항목(권한 범위 내)을 모아 요약 노출한다.
- **달성 가치**: V6
- **검증 방법**: 시스템 알림 발생 → 위젯에 반영되는지 확인.
- **비고**: iOS는 다른 앱의 알림에 대한 직접 접근을 제한한다. 본 앱이 직접 발행한 알림(루틴, 투두 마감 등)을 모아 표시하는 형태가 현실적 구현이다. 시스템 알림 직접 접근이 불가하다면 이 점을 사용자에게 명시한다.

### AC7: 갱신 주기
- **설명**: iOS 위젯 정책 내에서 가능한 한 자주 갱신된다. 사용자가 위젯을 봤을 때 정보가 정체되어 보이지 않을 수준의 신선도를 유지한다.
- **달성 가치**: V6
- **검증 방법**: 시간 경과에 따른 정보 갱신 확인.

### AC8: 위젯 영역 탭 시 앱 진입
- **설명**: 위젯 내 각 정보 영역을 탭하면 앱 내 해당 탭/화면으로 진입한다 (예: 문장 영역 탭 → 자주 읽는 문장 탭).
- **달성 가치**: V6
- **검증 방법**: 각 영역 탭 → 대응 화면 진입 확인.

## 열린 질문

- **알림 모음의 정의**: 시스템 알림은 iOS 정책상 직접 접근 불가. 본 앱이 발행한 알림으로 한정할 것인지, 또는 사용자에게 알림 형태를 더 명확히 정의받을 것인지 확인 필요.
